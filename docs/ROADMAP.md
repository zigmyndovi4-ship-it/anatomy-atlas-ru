# Product roadmap

## P0 — current product readiness

- stability and reproducible check/build;
- credits, licenses, and source attribution;
- complete Russian localization and RU/EN switching;
- README and product documentation;
- search, mobile, loading, and interaction QA.

## P1 — next product improvements

- desktop app packaging;
- stronger search ranking and matching;
- favorites;
- richer structure cards;
- related structures and navigation between them.

## P2 — educational expansion

- guided learning mode;
- broader automated tests;
- saved scenes;
- optional AI explanations, subject to a later privacy and architecture review.

P1 and P2 are not implemented in this nightly pass. No analytics, advertising, telemetry, payment systems, or external APIs are planned as prerequisites.

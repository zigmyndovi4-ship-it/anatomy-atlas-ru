# Contributing to Anatomy Atlas RU

Спасибо за помощь проекту.

## Локальный запуск

```sh
npm install
npm run dev
```

Приложение откроется на <http://localhost:3016>.

## Проверки

Перед pull request запустите:

```sh
npm run test:smoke
npm run test:e2e
npm run check
npm run build
```

## Issues и bug reports

Опишите шаги воспроизведения, браузер, viewport, язык интерфейса и ожидаемое
поведение. Для визуальных проблем приложите screenshot или короткую запись.
Не прикладывайте секреты, токены или персональные данные.

## Исправления терминологии

Предлагайте конкретный `conceptId`, исходное `en`, текущий `ru`, предлагаемую
форму и источник/обоснование. Медицинские изменения должны быть проверяемыми;
простая грамматическая коррекция и изменение медицинского варианта — не одно и
то же.

Не изменяйте `conceptId`, английские поля `en`, `atlas.json` или геометрию без
необходимости. Для спорных форм лучше открыть issue и оставить их на review,
чем вносить неподтверждённый перевод.

## Pull requests

Держите PR небольшим и описывайте, какие проверки прошли. Сохраняйте MIT
license, BodyParts3D attribution, сведения об исходном авторстве Human Atlas и
условия CC BY 4.0.
